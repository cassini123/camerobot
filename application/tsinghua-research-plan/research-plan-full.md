# 攻读研究生阶段学习与研究计划

**申请方向：** 清华大学深圳国际研究生院 · 电子信息（互动媒体设计与技术 / 互联网+创新设计）

**申请人研究主题：** 媒介如何让「此刻」可被记录、可被协作、可被再制造

---

## 一、统一研究立场

我关心的不是「再做一个更好用的 App」，而是：**在影像、历史书写、物质制造三种介质上，人如何以更低门槛把意图变成可验证的结果。**

今天的创作者并不缺灵感截图，缺的是从灵感到可执行动作之间的中间层；历史并不缺文本档案，缺的是能被当下借鉴的、可体验的关系与选择；制造并不缺渲染图，缺的是从布料到成品的、家庭/工作室尺度的可制造路径。三者横向看都很大——影视工业、公共记忆、再工业化——但研究生阶段我只在每个方向上选择**一个可答辩、可度量的纵向切口**。

工作方法对标 MIT Media Lab 课题组常见写法：先用一句可争论的愿景定场域，再写解决方案中立的问题陈述，最后落到 1–3 个小而深的研究问题、方法与成功标准。实践上以 **CameraRobot × Everec** 为主线（已有竞赛拆分、软件骨架与开源硬件时间表），另两题保持同等清晰的问题表述，作为方法迁移与第二年加深选项。

价值观锚点可以收为一句：**做你人生的导演——把此刻变成可被世界理解与记住的痕迹。** 研究计划不展开抒情，而把这句话落实为可设计的系统边界。

**英文 one-liners（面试/作品集可用）**

| 方向 | One-liner |
|------|-----------|
| CameraRobot / Everec | Liberate cinematic craft from the crew room: modular capture robots + language-driven production middleware. |
| 历史游戏 | History need not only be chronicled—it can be played as a living network of relations. |
| 材料与制造 | Make manufacturing domestic again: from cloth to garment, what you see becomes what you can make. |

## 二、课题一：CameraRobot × Everec

### 愿景标题

**把电影感从剧组解放到日常：可拆卸摄影机器人 + 自然语言驱动的创作中间层**

> Liberate cinematic craft from the crew room.

### 问题陈述（横向大、解决方案中立）

**Who：** 自媒体与旅拍创作者、小型剧组与学生影像团队，以及难以维持专业班底却需高频出片的独立导演。

**What：** 他们困在两套割裂的工具世界——重型工业流程门槛高；封闭消费 App 又难承接「参考—分镜—拍摄—成片—协作」闭环。灵感停在相册，时间耗在工具切换，而非创作判断。

**Where / When：** 手机相册、网盘、临时剧组沟通与外拍现场；尤其在「只有参考影像、没有完整班底」的超短片生产中。

**Why：** 缺少消费级可组装拍摄硬件，也缺少把自然语言与参考影像翻译为**可执行镜头表**的开放中间层。

**综合陈述：**  
影视门槛往往是工具链与协作链的门槛。业余高频创作与小型工业协作之间，需要**轻量、可拆卸、可开源扩展的硬软件系统**，使人从参考影像出发，以更低摩擦完成拍摄与轻量成片，把时间还给创作。

### 纵向小切入（研究问题）

1. **模块化摄影机器人的人机与工程边界**  
   在「更轻、便携、消费级可组装」约束下，底座（轻量移动底盘）— 中部（能源管理、储物、升降）— 顶部（手机固定/转向；Plus 版可承载可飞单元）如何定义可重复组装的开源硬件接口？基础版与 Plus 版的能力边界应如何切分，才能既可开源传播，又能为影视外拍提供新的可能？

2. **自然语言驱动的影视流程中间层**  
   如何将参考分析、灵感库、视觉解析、轻量剪辑与任务拆解收敛为可评估的管线：**灵感 → 可执行镜头表 → 轻量成片**，而不是功能堆砌？中间层输出应可被人类导演编辑，而非黑箱一键成片。

3. **协作效率是否可被度量**  
   对业余创作者与小型剧组，该中间层是否显著降低「从灵感到可拍镜头表」的时间与沟通成本？成功标准应可对照实验或工作坊验证。

### 系统定位（方法，非产品清单）

硬件 **CameraRobot** 与软件生态 **Everec（每刻）** 是同一问题的两面：硬件解决「在场记录与机位可达」，软件解决「意图到镜头与成片的翻译」。Everec 强调此刻的可记录性；工程上是一组可分可合的组件。研究生阶段**纵向深挖**参考解析、镜头切分与分镜表、轻量成片质量与自然语言任务拆解；灵感库、听觉与协作提醒等仅作系统周边，不并行做成多条同等深度的产品线。

已有基础：竞赛中持续拆分软件分支；仓库已具备「参考图/视频 → 分析 → 镜头规划」骨架。计划 **2027 年上半年** 开源基础硬件；**研究生阶段**推进 Plus（顶部可飞单元、中部自动电池管理的可实现子集）并完成协作管线用户验证。

### 方法与验证

- **硬件：** 模块定义、组装时间、开源文档与 BOM；Plus 在可控场景验证能源与顶部接口。  
- **软件：** 参考解析 + 分镜表 + 轻量剪辑为纵向对象；自然语言输出必须可编辑，拒绝黑箱一键成片承诺。  
- **用户研究：** 传统工具链对照 Everec；记录组装时间、镜头表采用率、成片交付时长、创作时间占比。  
- **作品证据：** 1–2 部系统支撑短片 + 开源发布。

### 成功标准（示例）

| 标准 | 描述 |
|------|------|
| 组装可达 | 非专业用户按文档完成基础版组装，中位时间可记录且可改进 |
| 镜头表可用 | 系统生成的分镜/镜头表经导演少量编辑后，≥70% 条目可直接用于拍摄 |
| 时间还给创作 | 对照实验中，「工具与沟通」耗时下降可统计；创作决策时间占比上升 |
| 开源可复现 | 基础版硬件与核心软件流程可被第三方按文档复现最小演示 |

## 三、课题二：历史游戏——用游戏书写世界的此刻

### 愿景标题

**史书不必只是严肃编年：用游戏引擎书写世界的此刻**

> History need not only be chronicled—it can be played.

### 问题陈述（横向大、解决方案中立）

**Who：** 希望从历史中获得「可借鉴于今天」的洞见的学习者、叙事设计师，以及试图表达公共记忆与当下社会关系的互动媒体创作者。

**What：** 正史文本擅长编年与考证，却不易让人体验「关系如何演变、选择如何代价化」；多数历史题材游戏则停在关卡叙事或美术复刻，世界像布景，人物像任务发放器，难以形成可迁移的理解。

**Where / When：** 教育与文化传播场景、独立游戏与互动叙事作品、数字孪生城市/时期切片的展览与研究原型中。

**Why：** 缺少把自然语言中的人物、事件、关系稳定映射为**游戏状态**（尤其是关系网络）的引擎层；时间、地图、人物系统若同时做大，研究不可控。

**综合陈述：**  
若历史的当代意义在于被借鉴，则书写形式可以不止于严肃编年。问题不在于否定史学，而在于：**如何以游戏化方式书写「关系中的此刻」**，使虚拟孪生场景的风格、人物性格的外观与动作、语义分析得到的关系网络，共同构成可玩、可读、可反思的小世界。

### 纵向小切入（研究问题）

1. **性格 → 外观/动作的可解释映射**  
   自然语言描述的人物性格，如何稳定映射到风格化虚拟角色的视觉参数与行为参数？映射是否可解释、可编辑，而非一次生成不可改？

2. **关系网络作为核心游戏状态**  
   在时间运行、人物、地图、关系四系统中，研究生阶段**只深挖关系边的生成—冲突—更新**如何触发可玩事件；时间与地图保持最小可用，避免大世界工程。

### 方法与验证

- 选定「一城 / 一短时段」切片，而非通史。  
- 以知识图谱/语义关系为辅助，构建关系引擎原型；输入可为史料摘要、口述或当代新闻叙事（明确标注虚构与史料边界）。  
- 对照传统脚本关卡：评估 emergent narrative 的**可读性、冲突可理解性、以及对当下问题的可借鉴讨论质量**（不把考据正确性作为唯一标准，但必须透明标注）。  
- 交付：可玩原型 + 设计文档 + 短论文式反思（历史书写伦理与游戏机制）。

### 成功标准（示例）

| 标准 | 描述 |
|------|------|
| 映射可编辑 | 用户能理解并修改「性格→行为」规则，且修改后行为变化可感知 |
| 关系驱动事件 | ≥50% 关键事件由关系状态变化触发，而非纯脚本触发 |
| 可借鉴讨论 | 游玩后被试能写出与当下相关的借鉴点，质量可用量表或专家评议 |

## 四、课题三：世界材料与制造——从布料开始的所见即所得

### 愿景标题

**制造再次家庭化：从布料开始，所见即可制造**

> Make manufacturing domestic again—from cloth to garment.

### 问题陈述（横向大、解决方案中立）

**Who：** 希望参与服装与日常物创造的个人、独立设计师、工作室尺度的制作者，以及关心生产尺度回移的设计研究者。

**What：** 工业化流水线满足了规模需求，却拉远了人与材料、工艺的距离；个性化期待上升时，人们面对的仍是「好看的效果图」与「不会做/做不出」之间的鸿沟。服装最贴近身体，却仍受打版、打样与工艺门槛强烈约束。

**Where / When：** 家庭与工作室、校园工坊、小规模定制场景；从想法出现到第一次可穿实物的过程中。

**Why：** 自然语言与视觉生成多停留在图像层；材料知识、版型约束与家庭/工作室设备能力未进入同一套「可制造描述」。制造工具革新若只做电商前端，不会改变「能否做出来」。

**综合陈述：**  
当生产力与需求结构变化，制造是否可能借助软硬件协同，再度回到小规模、「家庭化」的创造？问题的关键不在渲染真实感，而在：**从布的材料开始，把所见转化为受工艺与设备约束的可执行制造描述，并在真实打样中验证边界。**

### 纵向小切入（研究问题）

1. **自然语言 + 视觉 → 可制造服装描述**  
   用户描述与参考图如何转为材料—版型—工艺约束，而非仅生成好看渲染？失败时系统如何说明「不可制造」的原因？

2. **从「布」出发的最小闭环**  
   选定一种面料与工艺路径，在家庭/工作室设备上验证所见即所得的可行边界：精度、废料、时间、一次打样成功率。

### 方法与验证

- 设计研究：访谈独立制作者与服装相关学习者，梳理材料—工具—失败模式。  
- 原型：视觉/语言输入 → 结构化制造单（材料、裁片、步骤、设备假设）→ 实物打样。  
- 明确不做完整「制造万物」平台；万物是愿景，**服装最小闭环**是切口。  
- 交付：若干套打样记录、失败案例库、界面与工艺约束文档。

### 成功标准（示例）

| 标准 | 描述 |
|------|------|
| 描述可执行 | 制造单可被有基础缝纫能力的人按步骤完成，无需口头补充关键工艺 |
| 边界诚实 | 系统对超出设备/材料能力的请求给出可理解的拒绝或降级方案 |
| 打样证据 | 至少完成 N 次从描述到可穿实物的闭环，并公开废料与工时数据 |

## 五、三题关系与精力配置

```text
        「此刻」如何被媒介化
                 │
     ┌───────────┼───────────┐
     ▼           ▼           ▼
  影像记录     历史/关系     材料制造
 CameraRobot   历史游戏     服装闭环
   Everec      关系引擎     可制造描述
     │           │           │
     └──── 主线 ─┴─ 方法迁移 ┘
```

- **主线（申请与答辩重心）：** CameraRobot × Everec——与互动媒体、影视流程、人机协作、软硬一体最直接对齐。  
- **副线（同等清晰的问题，第二年择一加深）：** 历史游戏的关系引擎，或服装所见即所得最小闭环。另一题保持 Media Lab 式问题简报与探索笔记。  
- **方法迁移：** 自然语言 → 结构化可执行物（镜头表 / 关系事件 / 制造单）是三题共用的设计模式；知识图谱与可编辑中间层在影像与历史题中可复用。

面向 **IMDT（互动媒体设计与技术）**：强调叙事、人机协作、互动系统与作品证据。  
面向 **互联网+创新设计**：强调发现问题、软硬协同、开源与可落地的创新设计闭环。

## 六、研究生阶段学习与研究安排

### 第一年：立问题、出开源、做纵向实验

- 补齐互动媒体/创新设计方法、多媒体基础与用户研究。  
- CameraRobot 基础版开源；Everec 跑通「参考 → 镜头表 → 轻量成片」最小管线并做小规模工作坊。  
- 历史/制造：文献与田野笔记 + 问题简报细化。

### 第二年：Plus 与用户实验；副线择一加深

- Plus 原型（可飞接口与能源管理）与自然语言协作对照实验。  
- 副线二选一：关系引擎可玩切片，或服装最小制造闭环。

### 第三年：成体系交付与公开

- 主课题论文/毕业作品（系统 + 短片/工作坊 + 开源）；副线作附录或可延续项目。  
- 写清伦理：影像同意、历史虚构边界、制造废料与劳动。

## 七、预期成果

1. CameraRobot 基础版开源硬件与文档；Plus 原型与实验报告。  
2. Everec 核心中间层可运行原型（非全功能商业套件）。  
3. 至少一部系统支撑的短片或系列超短片，以及用户研究数据。  
4. 历史游戏或服装制造其一的可演示原型与设计反思文本。  
5. 面向 IMDT / 互联网+创新设计培养目标的学位论文与公开分享。

## 八、结语

电影感短片并不难——难的是把行业里对影像的理解，拆成低门槛、可协作、可验证的系统。历史可以被玩成关系，制造可以回到身边的布料：它们与摄影机器人一样，都在问**媒介能否诚实、可编辑地把人的意图接到世界上。** 研究生阶段我将把这个问题做窄、做实，并期待在清华跨学科环境中，让更多优秀作品因工具让路于创作而诞生。
