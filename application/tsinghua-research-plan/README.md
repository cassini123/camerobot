## 三课题 one-liners

1. **CameraRobot / Everec** — Liberate cinematic craft from the crew room.
2. **历史游戏** — History need not only be chronicled—it can be played.
3. **材料与制造** — Make manufacturing domestic again—from cloth to garment.

主线为 CameraRobot × Everec；历史游戏与材料制造在完整计划中同等写清问题，执行上第二年择一加深。
