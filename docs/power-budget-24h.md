# 功耗预算与 24h 续航口径

## 1. 结论

| 问题 | 答案 |
|------|------|
| 能否 24h **连续** 录制 + 满血 NPU + 持续移动？ | **否**（Base/Plus 均不承诺） |
| 能否 24h **日历日** 待机 + 间歇出片？ | **Base 可以**（外置包 + 休眠）；**Plus 需热插拔或回充桩** |
| 太阳能能否撑主动力学？ | **否**，只补待机 / 慢充 |
| 液压 / 机械能发电？ | **否**，量级远小于推进与计算 |

对外话术统一为：**全天活动跟拍（间歇）**，并写明 **累计有效拍摄小时数 X**，而非「24h 不停机」。

## 2. Base 功耗账

| 工况 | 约功耗 | 连续 24h 能量 |
|------|--------|----------------|
| 待机（MCU + 云台锁） | 1–2 W | 24–48 Wh |
| 录制 + 手机推理 + 云台跟拍 | 8–15 W | 192–360 Wh |

便携配置假设：手机电池 + **20–40 Wh** 外置包。

| 模式 | 粗算续航 |
|------|----------|
| 连续录制跟拍 | 约 **2–4 h** |
| 日均有效拍摄 1–2 h + 其余深睡 | **可覆盖一个活动日历日** |

产品定义示例：

> Base 续航：典型活动日待机 12–24 h，累计有效跟拍录制约 2 h（外置 30 Wh + 手机电量，环境 25°C）。

## 3. Plus 功耗账

| 子系统 | 待机 | 典型动作峰值 |
|--------|------|----------------|
| 底盘 | 3–8 W | 30–80 W 移动 |
| 升降 / 伸缩 | 1–3 W 抱闸 | 40–150 W 短时 |
| 算力板 | 5–12 W | 15–30 W 满推理 |
| 相机 / 云台 / 灯 | 2–8 W | 10–40 W |
| 无人机舱待命 / 充 | 1–5 W | 充电峰值更高 |

### 3.1 工况合成

**间歇拍摄日**（设计默认可达成目标）：

- 移动占空比约 10%
- 升降 / 滑轨偶发短脉冲
- NPU 跟拍约 2–3 h
- 其余时间低功耗待命或回充

粗算日均 **15–35 W** → 全日能量 **约 360–840 Wh**。  
对应：较大扫机级电池包，或 **双包热插拔（例如 2×300–400 Wh）** + 回充桩。

**连续 24h 跟拍巡航**：

- 平均 **50–100 W+**
- 能量 **约 1.2–2.4 kWh**
- 体积重量接近小型电动车电池 → **与产品形态冲突，判不可行**

### 3.2 太阳能与机械能

| 来源 | 实用量级 | 用途 |
|------|----------|------|
| **仰角跟踪半刚性阵列（推荐 100 W / ~0.5 m²）** | 晴天约 **130–220 Wh/日** | 待机与间隙慢充；详见 [solar-array-and-tracking.md](solar-array-and-tracking.md) |
| 固定平铺小顶盖 | 约 90–160 Wh/日（同面积更低） | 仅 MVP |
| 升降再生 / 制动回收 | 边角 Wh 级 | 不可作发电主力 |

## 4. 电池与补给策略（选定）

### Base

1. USB-C 可换充电宝；拍摄间隙接电。
2. App「低功耗跟拍」：降 FPS、降预览分辨率、云台限速。
3. 宣传口径绑定 **累计有效拍摄小时**，不承诺连续 24h 录制。

### Plus（选定：多块热插拔 + 太阳能补充）

1. **多块热插拔电池**：作业中轮换；一包工作、其余充电或待命。
2. **扫地机式自动回充桩**：`battery_pct < threshold` → 暂停运镜 → 回充 → 恢复队列中的分镜。
3. 任务调度：低电量禁止无人机与高速底盘；A7M4 长录制时优先保相机供电轨。
4. **太阳能顶盖**：只计入待机/慢充，不计入主动工况承诺 Wh。

#### 4.1 推荐容量（多电池方案）

间歇拍摄日母船约需 **360–840 Wh/日**（见 §3.1）。推荐配置：

| 配置 | 单包 | 数量 | 在机可用能量 | 用途 |
|------|------|------|--------------|------|
| 起步原型 | **200–250 Wh** | **3 块** | 约 400–500 Wh（2 在机热插拔） | 验证换电流程 |
| 活动日主力 | **250–300 Wh** | **3–4 块** | 约 500–600 Wh 在机 + 轮换 | 日均有效跟拍 2–3 h |
| 重度外拍 | **300–400 Wh** | **4 块** | 约 600–800 Wh 在机轮换 | 接近日需求上沿 |

电压平台建议 **36–48 V** 动力母线，相机/NPU 用 DC-DC 隔离。  
Mini 4 Pro **自带飞行电池**，母船另备 1–2 块无人机电池即可，不并入大母线容量计算。

**太阳能补充（现实预期，见专用文档）：**

| 条件 | 日补充能量（粗算） |
|------|-------------------|
| **100 W 级 + 仰角跟踪**，户外晴天 | 约 **130–220 Wh/日** |
| 同面积固定平铺 | 约 **90–160 Wh/日** |
| 阴天 / 室内 | 接近 **0** |

太阳能适合拉长待机、减慢掉电，**不能替代第三块电池**。板面积、倾角机构与互锁见 [solar-array-and-tracking.md](solar-array-and-tracking.md)。

#### 4.2 升降台耗电水平

摄影用电动丝杆/剪叉（负载含 A7M4+镜头+云台，约 1.5–3 kg 平台侧）：

| 状态 | 约功耗 | 说明 |
|------|--------|------|
| 到位抱闸 / 断电自锁 | **1–5 W**（理想接近 0） | 绝大多数时间 |
| 慢速微调高度（几 cm/s） | **30–80 W** | 持续数秒 |
| 满行程快速升降 | **80–150 W** 峰值 | 短时 5–20 s |
| 单次 0.5 m 行程能量 | 约 **0.5–2 Wh** | 远小于底盘巡航 |

结论：升降是 **短脉冲负载**，日均能量通常 **&lt; 20–40 Wh**（几十次调机位）；续航瓶颈在底盘移动 + NPU + 相机录制，不在升降本身。液压方案待机泄漏与维护成本更高，原型仍优先丝杆。

建议设计点：

| 参数 | 初值 |
|------|------|
| 回充阈值 | 20–25% |
| 恢复作业阈值 | 60–70% |
| 单包标称 | **250–300 Wh** × 3–4（多电池轮换） |
| 热路径 | NPU 与电池仓隔离，避免高温降额误判续航 |

## 5. 对外续航口径（必须遵守）

**允许：**

- 「支持全天活动间歇跟拍（含待机）」
- 「Plus 支持热插拔电池 / 自动回充，延长作业日历日」
- 「有效跟拍约 X 小时（见规格表工况）」

**禁止：**

- 「24h 连续 4K 录制」
- 「24h 满血 AI 视觉」
- 「太阳能实现全天不停机作业」

## 6. 与软件的挂钩

- `ShotPlan.safety` 可扩展 `battery_policy`: `return_to_dock | hot_swap_wait | degrade_vision`。
- Edge Vision 在 `degrade_vision` 下降到检测 10 FPS、关闭姿态分支。
- Everec 成片在补给/换电后于端侧 App 执行，不增加机载峰值功耗。

工况测量验收（原型）：

1. 记录各子系统电流（分流电阻 / INA 系列）。
2. 跑「间歇拍摄日」脚本 4 h，外推 24 h Wh。
3. 连续巡航压力测试只用于标红上限，不写入用户承诺。
