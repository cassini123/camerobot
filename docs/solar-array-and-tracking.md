# Plus 太阳能阵列尺寸与仰角跟踪

设计目标：在机身可铺面积内放得下、不挡相机/无人机，用 **仰角（高度角）单轴跟踪** 尽量吃满日照；太阳能仍是 **待机/慢充补充**，不替代多块热插拔电池。

## 1. 推荐装机规格（可直接写进外观/结构）

| 项 | 推荐值 | 说明 |
|----|--------|------|
| **STC 标称功率** | **80–120 W**（主力档 **100 W**） | 户外晴天峰值；机载实际常为 0.55–0.75×STC |
| **铺板面积** | **0.45–0.65 m²** | 按高效单晶约 180–220 W/m² STC 反推 |
| **板型** | 半刚性碳纤维背板 + 单晶 PERC/TOPCon，或车规柔性板贴背板 | 纯软胶柔性板效率与散热更差，优先半刚性 |
| **重量预算** | **1.2–2.0 kg**（含转轴/驱动） | 超过 2.5 kg 会明显抬高重心与倾覆风险 |
| **系统电压** | 与 36–48 V 母线匹配的 MPPT（或板端升压到母线） | 独立 MPPT，勿与电机总线硬并联 |
| **跟踪自由度** | **单轴仰角（tilt / elevation）** | 性价比最高；双轴留给基站/拖车版 |

**不建议：** 为了「看起来很大」堆到 200 W+ 面板——面积、风载、重心和无人机舱冲突会先爆。

### 1.1 面积怎么来的（量级）

近似：

\[
P_\mathrm{STC} \approx A \times 1000\,\mathrm{W/m^2} \times \eta
\]

- \(\eta \approx 0.20\) → \(0.5\,\mathrm{m^2} \Rightarrow \sim 100\,\mathrm{W}\)
- 机体顶盖可用宽约 350–450 mm、长约 500–700 mm（含可倾转外伸），总投影约 **0.5 m² 级**
- 侧翼可折叠补光板（可选 +30–50 W）：展开仅在 **驻停补电模式**，跟拍时收回

### 1.2 日发电粗算（设计记账用）

| 工况 | 固定接近水平 | **仰角跟踪（本方案）** |
|------|--------------|------------------------|
| 晴天、中纬度春分附近 | 约 90–160 Wh/日 | 约 **130–220 Wh/日** |
| 晴天、夏至（太阳高） | 约 120–200 Wh/日 | 约 **150–240 Wh/日** |
| 晴天、冬至（太阳低） | 约 40–90 Wh/日 | 约 **80–150 Wh/日**（跟踪收益最大） |
| 阴天 / 树荫 / 室内 | ≈ 0–40 Wh | 同左 |

跟踪相对「平铺顶盖」大约 **+20%～+40%** 日能量；冬天和早晚更明显。  
相对「完美双轴对日」大约少 5–15%，但机构简单一个数量级。

对照间歇作业日耗电 360–840 Wh：太阳能大约覆盖 **15%–40% 待机+慢充份额**，仍需 3–4 块电池轮换。

## 2. 仰角跟踪：跟着太阳高度角走

### 2.1 选单轴仰角，不先做方位双轴

| 方案 | 增益 | 复杂度 | Plus 建议 |
|------|------|--------|-----------|
| 固定 0°（平铺） | 基线 | 最低 | 仅 MVP 外观件 |
| **单轴仰角 tilt** | +20–40% | 中 | **量产设计默认** |
| 方位 yaw + 仰角 | +30–50% | 高 | 与相机朝向/无人机舱抢自由度，后期可选 |
| 底盘转向对日 | 中等 | 低机构/高导航 | 仅「补电站桩模式」可用，拍摄时禁用 |

**默认策略：** 板子做 **pitch 仰角 0°–70°**（相对水平）；方位靠：

1. 补电驻停时底盘缓慢自转对南/对日方位（低优先级任务）；或  
2. 用户把机器停成大致朝阳。

拍摄跟拍时：**锁定当前 tilt**，禁止连续对日转动，避免画面晃与风载突变。

### 2.2 高度角开环公式（固件可算）

用日期、纬度、本地时计算太阳高度角 \(\alpha\)（elevation），目标板法线尽量对准太阳：

- 板倾角 \(\beta\)（相对水平，0=平躺，90=竖立）取：

\[
\beta^\star \approx \mathrm{clamp}\big(90^\circ - \alpha,\; \beta_\min,\; \beta_\max\big)
\]

推荐限位：

| 参数 | 值 |
|------|-----|
| \(\beta_\min\) | **5°**（排水、落灰，避免完全 0° 积水） |
| \(\beta_\max\) | **65°–70°**（再竖风载过大，且挡镜头风险升） |
| 跟踪死区 | \(\lvert\beta - \beta^\star\rvert < 3^\circ\) 不动 |
| 更新周期 | 补电模式 **30–60 s**；移动拍摄 **锁定** |

可选闭环：板缘 4 象限光敏/小型日照传感器微调 ±5°，抑制公式时区误差。

### 2.3 机构草图（给 ID/结构）

```text
侧视（拍摄姿态，板可锁）：

        [Mini 舱 / 云台区]     <-- 板不得扫入此包络
              |
     ╱太阳能板 β               <-- 转轴在机身后上沿
    ╱    ↑ tilt actuator
   [机身顶盖 / 储物]
   [电池仓]
   [底盘]
```

要点：

- **转轴放在机身背部上沿**，板向前上方仰起时，前缘低于云台最低工作包络。
- 与 **无人机舱门** 互锁：舱门开或无人机未入舱 → \(\beta\) 强制收至 ≤15°。
- 与 **升降最高位** 互锁：lift 高于阈值时禁止增大 \(\beta\)。
- 驱动：蜗轮 / 带自锁丝杆，**断电自锁**；峰值电机 **5–15 W**，跟踪平均 **&lt; 1–2 W**（远小于面板产出）。
- 风载：\(\beta>45°\) 且风速估算高时自动收板到 15°。

### 2.4 模式状态机

| 模式 | 太阳能行为 |
|------|------------|
| `shooting` / `tracking_subject` | 锁定 tilt；MPPT 能收就收 |
| `idle_outdoor` | 开环仰角跟踪；可选底盘慢速对日方位 |
| `dock_charging` | 收板或平铺，优先桩充 |
| `drone_deploy` | 强制收板 |
| `stow` / 运输 | \(\beta=5°\) 机械锁 |

软件域建议：`solar = { tilt_deg, mode, mppt_watts, wh_today }`，进眼睛屏与 App 电量页。

## 3. 外观可写进设计的「一句话规格」

> Plus 背部半刚性太阳能模块，STC **100 W / 约 0.5 m²**，重量 ≤ 2 kg；**单轴仰角 5°–70°** 跟随太阳高度角，补电驻停时可底盘辅助对日；拍摄与开舱时锁板。晴天典型补充约 **150–220 Wh/日**，用于待机与慢充，不替代热插拔电池组。

## 4. 与电池方案的配合

- 太阳能输出 → MPPT → 优先给「正在充电的离位电池包」或母线浮充。
- 日补 150–220 Wh ≈ **半块到一块 250 Wh 包的慢充**，适合活动间隙趴在户外补电。
- 规格书禁止写「太阳能全天供电」；可写「户外待机延长 / 间隙补电」。

## 5. 验收（原型）

1. 固定 5° vs 仰角跟踪，同地同日各测 4 h，比 Wh（INA 电量计）。  
2. 开舱 / 最高升降时硬限位是否触发。  
3. 侧风 8–10 m/s 模拟：是否自动收板。  
4. 跟踪电机日耗电应 **&lt; 日发电的 5%**。
