# Camerobot Base / Plus 硬件 SKU

本文定义双 SKU 机械与电子边界、快拆/供电/通信接口，以及无人机舱分期。软件与续航见：

- [edge-vision-and-everec.md](edge-vision-and-everec.md)
- [power-budget-24h.md](power-budget-24h.md)
- [solar-array-and-tracking.md](solar-array-and-tracking.md)（100 W 级阵列 + 仰角跟踪）
- [test-stack-a7m4-mini4pro.md](test-stack-a7m4-mini4pro.md)（开发测试：A7M4 + Mini 4 Pro）

## 1. SKU 总览

| | Base | Plus |
|--|------|------|
| 定位 | 旅行 / 自媒体 / 活动便携出片 | 高要求移动摄影底座 |
| 相机位 | 手机（主） | 手机 → 微单快拆板 |
| 移动 | 无（手持 / 脚架 / 胸带） | 轮式底盘（类扫地机） |
| 升降 / 伸缩 | 无 | 电动丝杆升降 + 横向滑轨 |
| 无人机舱 | 无 | 分阶段（见 §5） |
| 算力 | 手机 NPU + ESP32 级 MCU | 边缘 NPU 板 + 运动 MCU |
| 干重目标 | ≤ 400–600 g（不含手机） | 8–15 kg（不含电池包） |

共享原则：Base 与 Plus 共用手机快拆夹具与冷靴附件生态；Plus 相机台上的夹具兼容 Base。

## 2. Base：手机位便携机

### 2.1 结构

```text
[折叠脚架 / 胸带接口]
        |
   [冷靴 / 1/4"-20]
        |
   [三轴或单轴迷你云台]
        |
   [磁吸 / 快拆手机夹]  <-- 1 秒取下手机
```

- 磁吸快拆：对齐销 + 磁吸，防滑垫；支持竖/横锁定。
- 云台：优先三轴；成本版可单轴 yaw + 机械俯仰。
- 可选：折叠脚架、胸带、冷靴补光灯座。
- **不做**：轮式底盘、液压升降、无人机舱、太阳能板。

### 2.2 电子模块（BOM 级）

| 模块 | 规格建议 | 备注 |
|------|----------|------|
| MCU | ESP32-S3（BLE + Wi‑Fi） | 只控云台与配件，不跑 YOLO |
| 云台驱动 | 无刷云台驱动板 / 现成云台模组 | 跟拍指令来自手机 App |
| 电源 | USB-C PD 入；可选 20–40 Wh 外置包 | 见功耗文档 |
| 传感 | IMU（云台内置即可） | 避障留给手机摄像头 |
| 指示 | 录制 LED + 隐私灯 | 与软件 `privacy` 状态一致 |

### 2.3 接口

| 接口 | 定义 |
|------|------|
| 机械快拆 | 磁吸板 + 防转销；兼容主流手机厚度范围 |
| 供电 | USB-C 5–9 V；云台可独立供电 |
| 通信 | BLE GATT（云台姿态、录制触发）；可选本地 Wi‑Fi 预览 |
| 附件 | 冷靴 + 1/4"-20 螺孔 |

## 3. Plus：移动摄影底座

### 3.1 结构分层

```text
[无人机舱 / 停机坪]          Head
        |
[三轴云台 + 相机快拆板]
        |
[横向线性滑轨 200–400 mm]   「推糖机」式推拉
        |
[电动丝杆 / 剪叉升降柱]     高度服务机位
        |
[储物舱 + 电池仓 + 算力舱]  Body
        |
[差速/三轮底盘 + 减震]      Base
        |
[回充对接触点]
```

### 3.2 模块选型结论

| 模块 | 选型 | 原因 |
|------|------|------|
| 移动底座 | 轮式差速或三轮，室内优先 + 轻户外 | 成熟、可做自动回充 |
| 升降 | **电动丝杆或剪叉优先**；液压仅后期重载选项 | 泄漏/维护/噪声；丝杆更适合微调 |
| 横向伸缩 | 相机平台线性滑轨，行程 200–400 mm，到位抱闸 | 推/拉运镜；防抖需锁死 |
| 能源 | 热插拔 36–48 V 电池包；**背部 80–120 W 半刚性板 + 仰角跟踪** | 见 solar 文档；拍摄时锁板 |
| 相机位 | 升降台上三轴云台 + 快拆板 | 与 Base 夹具共用 |
| 减震 | 底盘—升降柱—云台级联隔振 | 多自由度同时动时优先串行限速 |

### 3.3 电子模块（BOM 级）

| 模块 | 规格建议 | 备注 |
|------|----------|------|
| 运动 MCU | STM32 / 同类实时 MCU | 底盘、升降、滑轨、急停 |
| 边缘算力 | RK3588 / Orin Nano / Hailo 加速方案 | 见视觉文档 |
| 深度/避障 | 深度相机或 ToF + 保险杠碰撞条 | 与摄影 NPU 分核或分芯片 |
| 补光 | 头部/机身 PWM 色温灯 | 与构图闭环联动 |
| BMS | 热插拔双包或主+备用 | 支持作业中换电 |
| 回充 | 扫地机式触点底座 | 低电量任务调度回充 |
| 显示 | 眼睛显示屏（状态/预览/引导） | 沿用产品 README §2.3 |
| 太阳能驱动 | 自锁丝杆/蜗轮，仰角 5°–70° | 开舱/高升降互锁收板 |
| MPPT | 独立充电路径进 BMS | 平均跟踪功耗 &lt; 2 W |

### 3.4 接口

| 接口 | 定义 |
|------|------|
| 相机快拆 | Arca 风格或自研板；手机夹与微单板互换 |
| 电池 | 盲插热插拔连接器；键位防反插 |
| 回充 | 底盘前/底触点；对准容差 ±15 mm |
| 通信总线 | 机内 CAN 或 UART 星型到运动 MCU；算力板以太网/USB |
| 外部 | USB-C 调试、千兆网口（开发用）、急停硬按钮 |
| 无人机 | 阶段依赖（§5）：先 Wi‑Fi/SDK；后磁吸触点充电 |

### 3.5 安全硬约束

- 人体净空默认 ≥ 0.8 m；室内最大移速 ≤ 0.35 m/s。
- 急停切断底盘与升降动力；云台进入阻尼抱死。
- 升降/滑轨动作时底盘默认禁止同时高速平移。
- 隐私指示灯在录制/拍照时硬件级常亮。

## 4. HAL 域与硬件映射

与软件 `ShotPlan` / Body Control 对齐：

| HAL 域 | Base | Plus |
|--------|------|------|
| `base` | 无 / 脚架固定 | 轮式移动、回充 |
| `lift` | 无 | 丝杆/剪叉高度 |
| `extend`（新增语义） | 无 | 横向滑轨行程 |
| `head` | 迷你云台 | 三轴云台 |
| `camera` | 手机相机 API | 手机或微单控制 |
| `arm` | 无 | 可选轻摇臂（后期） |
| `lights` | 冷靴小灯 | 机身/头部灯 |
| `drone` | 无 | 见 §5 |
| `display` | 手机 UI | 眼睛屏 |
| `safety` | 隐私灯、云台限速 | 急停、防撞、限速 |

MVP0 代码中横向伸缩可先映射进 `arm` 或 `lift` 扩展字段；稳定后拆独立 `extend` 域。

## 5. 无人机舱分期

| 阶段 | 交付 | 风险 |
|------|------|------|
| P0 | 外部无人机 SDK/API：起飞、跟随、返航、素材同步 | 低；先验证空地衔接 |
| P1 | 头顶磁吸停机坪 + 定向充电触点；人工放机 | 中；对齐与防水 |
| P2 | 舱门开合 + 自动弹出/回收 + 舱内充电 | 高；卡死、夹伤、室内飞规 |

任何阶段室内飞行默认受 `constraints.indoor` 与法规开关约束；失败模式必须能手动开舱取机。

## 6. 原型优先级（与产品 README §9 一致）

1. Base 快拆手机云台 + 手机 App 跟拍。
2. Plus：低速底盘 + 丝杆升降 + 手机/轻微单云台 + 补光 + 眼睛屏。
3. 横向滑轨运镜。
4. 无人机 P0→P1；P2 最后做。
5. 液压与重载微单生态仅在负载与续航验证后再开。
