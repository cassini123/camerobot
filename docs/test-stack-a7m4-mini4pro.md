# 开发测试栈：Sony A7M4 + DJI Mini 4 Pro

## 1. 结论

| 设备 | 是否 OK | 角色 |
|------|---------|------|
| **Sony A7 IV (A7M4)** | **可以，作为 Plus 地面主相机原型** | 照片/视频成片质量高；重量与供电要按专业机设计 |
| **DJI Mini 4 Pro** | **可以，作为空中视觉与「复原」软件测试机** | 先跑航拍视觉识别/构图复原；不依赖自研舱门 |

两套设备并行：**地面闭环用 A7M4（或先用手机）**，**空中算法用 Mini 4 Pro 素材/SDK**。不要等舱门做好再测视觉。

## 2. Sony A7M4 注意点

- 机身约 650–700 g，加镜头常 **1.0–1.5 kg+** → 云台与升降负载按 **≥ 2 kg 安全余量** 选型。
- 供电：相机自带电池 + 机身 USB-C PD 外供更稳；不要只靠机器人母线硬扛长时间 4K。
- 控制：优先 **Camera Remote SDK / USB tethering / HDMI 监视**；快门与录制要进 HAL `camera` 域。
- 与 Base 手机夹：**快拆板互换**，软件同一套 `PhotoMode` / `VideoMode` 契约。

## 3. DJI Mini 4 Pro 注意点

- 适合：**航拍建立镜头、顶拍、跟拍轨迹、视觉复原软件离线/半在线测试**。
- 开发路径建议：
  1. 录制标准素材 → 本地跑检测/构图/光照估计（与地面同 API）。
  2. 再接 DJI SDK / 图传预览做半实时。
  3. 最后才做舱内充电与自动起降（硬件 P1/P2）。
- 限制：室内飞规与避障；风阻；与地面机器人时间同步靠 marker / 时间码，不要假设完美同步。
- Mini 4 Pro **不能**代替 A7M4 做人像主成片测试，但很适合验证「参考画面 → 机位/运动估计 → 复现」软件。

## 4. 软件模式对应

| 模式 | 输入 | 输出 | 典型设备 |
|------|------|------|----------|
| **照片模式** | 一张参考图 | 机位视角、人物位置、光照、效果、色彩 + 复现目标 | A7M4 / 手机 / Mini 静帧 |
| **视频分镜模式** | 分镜表（参考图/运镜/时长…） | 逐镜分析 + 运镜计划 + 时间轴 | 地面 A7M4 + 可选 Mini 航拍镜 |

CLI / API 见仓库 README；契约细节见 [edge-vision-and-everec.md](edge-vision-and-everec.md)。

## 5. 与电池策略的关系

A7M4 连续录制会明显拉高「相机/云台」支路功耗；Mini 4 Pro 用自带电池飞行，母船主要承担 **起飞前充电与待命**。容量选型见 [power-budget-24h.md](power-budget-24h.md) §4.1 多电池 + 太阳能。
